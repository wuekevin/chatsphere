# ChatSphere Experience Spec

视觉规范见 `DESIGN.md`；本文件管理**行为、结构、交互和流程**，所有颜色 token 引用 `{DESIGN.colors.*}`。

---

## Foundation

**产品形态：** Web 嵌入式 Widget（主要）+ Web 管理后台（Admin）。Widget 以 `<script>` 标签嵌入宿主页面，不控制宿主页面任何元素，行为完全自包含。

**UI 系统：** 无第三方 UI 框架。Widget 以 vanilla JS + 原生 CSS（scoped 到 `[data-cs="root"]`）实现；管理后台使用 Go 服务端渲染 HTML + 轻量 JS 增强（无 React/Vue）。视觉规范：`DESIGN.md`。

**主要表面：**
1. **Widget 折叠态** — 页面角落的悬浮按钮
2. **Widget 展开态** — 聊天主视图（频道头部 + 消息列表 + 输入区）
3. **Widget 私信抽屉** — 从侧边滑入的覆盖层
4. **Widget 覆盖层** — 登录/注册表单
5. **安装向导** — 独立页面 `:8080/setup`
6. **管理后台** — 独立页面 `:8080/{admin-path}`

## Information Architecture

### Widget IA

```
Widget (折叠)
└── Widget (展开)
    ├── 频道头部
    │   ├── 频道头像 / 名称
    │   ├── 在线人数 + 波形动画
    │   └── 关闭按钮
    ├── 消息列表（滚动）
    │   ├── 消息气泡（他人） ← 头像 · 昵称 · 国旗 · 徽章 · 时间戳
    │   ├── 消息气泡（自己） → 时间戳 · 徽章 · 国旗 · 昵称 · 头像
    │   └── 系统消息（Bot提示、频道公告）
    ├── 输入区
    │   ├── 输入框（占位符：「发送消息…」）
    │   ├── 表情按钮（SVG图标）

    │   └── 发送按钮（accent色圆角方形）
    └── [覆盖层] 登录/注册表单（进入时滑入）
        └── [抽屉] 私信视图（左侧滑入）
```

```

├── 顶栏（品牌名 + 页面标题 + 管理员头像）
```

## Voice and Tone

**品牌声音：** 轻松、直接、功能导向。Widget 面向普通用户（影视观众），语言口语化、简短；Admin 面向站长，语言精确、无歧义。

**Widget 文案原则：**
- 动词优先：「发送消息」而非「在此处输入」
- 操作反馈即时且简短：「消息已发送」「已举报」
- 匿名用户身份使用随机双词组合（形容词 + 名词，英文），中文界面时保留英文随机名（`Swift Hawk_MX9`），避免翻译歧义

**Admin 文案原则：**
- 危险操作必须有二次确认文案，明确说明影响范围：「封禁后该用户将无法在所有频道发言」
- 状态标签使用动名词或过去式：「已封禁」「处理中」「已忽略」
- 数字统计使用本地化格式：`1,284`（逗号分隔千位）

## Component Patterns

### 消息气泡（Behavioral）

视觉规范见 `{DESIGN.components.Widget 气泡消息}`。

**行为规则：**
- 消息列表默认固定在底部（`scroll-anchor`），新消息到来时：若用户已滚动至距底部 200px 内，自动滚动到底；否则显示「↓ 有新消息」浮动提示，点击跳至底部
- 时间戳仅在同一用户连续消息中间隔 ≥ 5 分钟时显示；相邻 5 分钟内的同用户消息不重复显示头像和昵称（节省空间）
- 被 @ 的消息：气泡外加 `box-shadow: 0 0 0 2px {DESIGN.colors.accent}`，高亮持续至用户滚动查看后消失
- 消息右键/长按（移动端）弹出操作菜单：「回复」「@ 他」「举报」（仅他人消息）
- Bot 系统消息：居中显示，`{DESIGN.colors.fg-subtle}` 文字，无气泡背景，前置机器人图标

### 输入区

- 输入框高度自动扩展，最大 4 行后出现内部滚动条
- 输入超过频道 `max_length` 时：边框变红，右下角显示剩余字符计数（红色）
- 触发速率限制时：发送按钮短暂禁用，倒计时显示在按钮上（`3s...`）
- 表情选择器：悬浮于输入框上方，显示 30 种常用表情的 emoji 网格（6×5）
- `@` 触发提及补全：输入 `@` 后出现在线用户下拉列表，键盘上下键选择，Enter 确认

### 私信抽屉

- 从 widget 左侧 `translateX(-100%)` 滑入，`transition: 280ms cubic-bezier(0.4,0,0.2,1)`
- 频道聊天视图不销毁，仅被遮盖；关闭抽屉后频道状态保持
- 抽屉顶部：`← 返回` + 对话者昵称 + 对话者在线状态点
- 未读私信：widget 折叠按钮角标叠加私信数字（蓝底白字，与@提及的红色区分）

### 声誉徽章

- 徽章作为 inline 元素跟随昵称显示
- 管理员在后台修改用户积分后，该用户下次发消息时徽章实时更新（不需刷新页面）
- 访客（ANON）不显示积分，仅显示 `ANON` 灰色徽章

### 登录/注册覆盖层

- 点击「登录/注册」按钮从底部滑入（`translateY(100%)`），覆盖消息列表和输入区
- 表单切换（登录 ↔ 注册）使用 Tab 切换，无页面跳转
- 登录成功后覆盖层下滑消失，恢复聊天视图，输入框自动获焦

### Admin 导航

- 侧边栏 active 项：`{DESIGN.colors.accent-dim}` 背景 + `{DESIGN.colors.accent}` 文字和图标（opacity 1）
- 非 active 图标：opacity 0.6，hover 时 opacity 0.9
- 移动端（<520px）：侧边栏折叠为图标条（44px 宽），文字隐藏，tooltip 显示

## State Patterns

### WebSocket 连接状态

| 状态 | 表现 |
|------|------|
| 连接中 | 频道头部在线人数位置显示动态省略号 `...` |
| 已连接 | 正常显示在线人数 + 绿色波形动画 |
| 断开/重连中 | 顶部细条显示黄色「重新连接中…」提示，输入区禁用 |
| 重连失败 | 提示「连接失败，点击重试」按钮；消息列表只读可滚动 |

### 消息发送状态

| 状态 | 表现 |
|------|------|
| 发送中 | 气泡 opacity 0.6，右下角显示 `⟳` 转圈 |
| 已发送 | opacity 1，`⟳` 消失 |
| 发送失败 | 气泡底部显示红色「发送失败，重试」文字链接 |
| 被 Bot 拦截 | 本地气泡消失，系统消息提示（频道内所有人可见） |

### 表单验证状态

- 输入框 focus：`border-color: {DESIGN.colors.accent}` + `box-shadow: 0 0 0 3px {DESIGN.colors.accent-dim}`
- 验证错误：`border-color: {DESIGN.colors.red}`，红色错误文字在输入框下方
- 验证成功（如安装向导连接测试）：绿色 `✓ Connected` 徽章

### 空状态

- 频道无消息：居中显示频道名 + 「成为第一个发言的人」
- 管理后台空列表：居中图标 + 说明文字 + 操作按钮（如「创建第一个频道」）
- 举报列表无待处理：绿色 ✓ 图标 + 「暂无待处理举报」

## Interaction Primitives

**动画时长：**
- 微交互（hover、focus、active）：80–120ms
- 覆盖层/抽屉滑入：280ms `cubic-bezier(0.4,0,0.2,1)`（Material Standard easing）
- 折叠/展开 Widget：320ms `cubic-bezier(0.4,0,0.2,1)`
- 新消息滑入（从底部 translateY 8px + fade）：160ms

**Hover 态：** 仅可交互元素（按钮、链接、nav item、气泡操作按钮）才有 hover 态。背景轻微加亮（`brightness(1.08)`）或 opacity 提升。不为纯展示元素添加 hover 视觉反馈。

**Focus 可见性：** 所有可交互元素有清晰的 focus outline，使用 `outline: 2px solid {DESIGN.colors.accent}; outline-offset: 2px`，不用浏览器默认蓝色 focus ring。

**触摸友好：** 所有可点击区域最小 44×44px（遵循 WCAG 2.5.5）。气泡上的操作通过长按触发操作菜单，不依赖 hover。

**减少动效：** 所有动画在 `prefers-reduced-motion: reduce` 时降级为瞬切。

## Accessibility Floor

- **颜色对比：** `{DESIGN.colors.fg}` 在 `{DESIGN.colors.surface}` 上对比度 ≥ 7:1（AAA）；`{DESIGN.colors.accent}` `#f5a623` 在深色背景 `#13151e` 上对比度约 6.8:1（≥AA）；自己的气泡白字在橙底上对比度约 3.5:1（满足 WCAG AA 大字体要求，12.5px bold）
- **键盘操作：** Tab 键可遍历所有输入区、按钮；消息列表支持上下方向键浏览；私信抽屉和覆盖层开启时焦点陷阱（focus trap）
- **屏幕阅读器：** Widget 根节点设置 `role="complementary" aria-label="ChatSphere 聊天窗口"`；消息列表设置 `role="log" aria-live="polite" aria-atomic="false"`；新消息通过 `aria-live` 自动播报发言者和内容
- **语音输入：** 输入框支持浏览器原生语音输入（`inputmode` 自然继承）；语音按钮需 `MediaDevices.getUserMedia` 权限，拒绝时按钮不显示
- **颜色非唯一信息载体：** 在线状态不仅靠颜色点，同时在 tooltip 显示 "在线"/"离线" 文字；徽章不仅靠颜色，同时显示文字标签（GOLD / SILVER / BRONZE）

## Key Flows

### KF-1：访客发出第一条消息（阿明）

**主角：** 阿明，第一次访问金帝影视，看到右下角聊天按钮。

1. 页面加载 500ms 后，折叠按钮以 `scale(0.8) → scale(1)` + fade 动画出现在右下角
2. 阿明点击按钮，Widget 以 `translateY(20px) → translateY(0)` + fade 展开（320ms）
3. 看到「影迷频道」头部，显示「248 在线」+ 绿色波形；消息列表加载最近 20 条历史
4. 阿明点击输入框（focus 橙色边框高亮），输入文字
5. 点击发送按钮（或 Enter），消息气泡以淡入动画出现在列表右侧（自己的橙色气泡）
6. 气泡 opacity 0.6（发送中）→ opacity 1（已确认）

**关键约束：** 整个流程不要求登录，步骤 4-6 在 10 秒内完成。

---

### KF-2：被 @ 提及通知（小林）

**主角：** 小林，Widget 处于折叠状态，正在浏览页面其他内容。

1. 另一用户发出包含 `@小林` 的消息，服务端推送 WebSocket 事件
2. 折叠按钮角标出现红色数字 `1`（`scale(0) → scale(1)` 弹出动画）
3. 同时播放 @ 提醒音效（默认内置音效，0.3s 短促提示音）
4. 小林点击折叠按钮，Widget 展开，消息列表自动滚动至被 @ 的消息，该气泡外框高亮（橙色 2px glow）
5. 小林阅读消息，高亮消失，角标清零

**关键约束：** 步骤 1-3 端到端 < 2 秒。

---

### KF-3：站长安装 ChatSphere（Kevin）

**主角：** Kevin，服务器上执行 `./chatsphere`，从未用过此产品。

1. 浏览器自动打开 `http://localhost:8080/setup`，全屏安装向导，步骤圆圈显示 5 步（Database / Cache / Admin / Site / Done）
2. **Step 1：数据库** — Kevin 填写 MySQL DSN，点击「测试连接」，2 秒内返回绿色 `✓ Connected` 徽章或红色错误（附错误原因）
3. **Step 2：缓存** — 同上，测试 Redis 连接
4. **Step 3：管理员** — 设置用户名 + 密码（强度指示条）+ 确认密码；密码字段右侧显示「显示/隐藏」切换图标
5. **Step 4：站点信息** — 填写站点名称、默认频道名称、管理后台路径（默认 `/admin`）
6. **Step 5：完成** — 点击「开始安装」，页面显示实时日志流（建表、创建管理员、生成 config.yaml）；日志完毕后出现「安装成功 ✓」大标题 + 「进入管理后台」按钮

**关键约束：** 步骤 1-6 总时长 < 30 分钟；任何步骤失败有明确错误提示（不静默）。

---

### KF-4：管理员配置 Widget 主题色

**主角：** Kevin，想把 Widget 的强调色改成绿色以匹配另一个网站。

1. 进入 Admin → Settings → Widget 主题
2. 看到当前强调色色块（`#f5a623`），点击打开颜色选择器（原生 `<input type="color">`）
3. 选择新颜色，页面内嵌 Widget 预览实时更新（无需保存）
4. 点击「保存」，服务端生成注入 CSS 片段，当前 Widget 嵌入脚本自动携带新主题

**关键约束：** 颜色变化在 Widget 预览中实时反映（< 100ms）；保存后新访客立即生效，已连接客户端下次刷新后生效。

## Responsive & Platform

**Widget：** 设计基准 340px 宽；在 ≤ 400px 视口下，Widget 展开后铺满屏幕宽度（`width: calc(100vw - 32px)`），保留左右各 16px 安全距离。移动端长按消息触发操作菜单（代替 hover）。

**Admin 后台：** 最小支持 768px 视口。移动端（<520px）侧边栏图标化，主要场景仍以桌面为主（站长通常在桌面操作后台）。

**安装向导：** 响应式，支持移动端完成安装（向导表单单列布局）。
