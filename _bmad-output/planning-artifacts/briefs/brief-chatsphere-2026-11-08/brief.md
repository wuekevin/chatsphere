# ChatSphere 产品 Brief

## 执行摘要

ChatSphere 是一款可嵌入任意网站或 App 的实时社区聊天系统。通过一行 `<script>` 标签，任何站长都能在自己的页面上运行一个完全自主掌控的聊天社区——数据在自己服务器上，样式随意定制，永不因平台封号而失去社区。

这个产品的诞生来自真实的痛点：运营影视内容的站长花了数年积累起来的 QQ 群社区，在一夜之间被封，粉丝无处聚集。像这样的站长不在少数。ChatSphere 要做的，就是把社区的基础设施还给内容创作者和独立站长，让他们不再被平台生杀予夺。

产品首先服务于自己的影视内容平台，同时向外出售——提供买断授权（自托管）和云托管订阅（SaaS）两种商业模式。

---

## 问题

内容创作者和独立站长通常依赖 QQ 群、微信群维系粉丝社区，但这条路越来越不可靠：

- **平台封号风险高**：涉及版权敏感内容的频道随时可能被封，毫无预警，多年积累的社区瞬间蒸发。
- **现有嵌入方案不适用**：Intercom、Crisp 等工具月费 $50–$500+，功能以客服为主，不是为粉丝社区设计的。
- **跳出式方案粘性差**：Discord、Telegram 频道需要用户离开网站，转化率低，也无法与站内内容联动。
- **自建门槛太高**：WebSocket、管理后台、用户系统一套下来，大多数站长没有能力从零开发。

代价很明确：社区丢失等于流量流失，用户粘性归零，多年运营积累付之一炬。

---

## 解决方案

ChatSphere 是一套完整的自托管嵌入式社区聊天平台。部署在自己的服务器上，数据完全自主，永远不会因平台政策消失。

- **嵌入 Widget**：一行代码嵌入任意页面，零依赖，样式完全隔离，不影响宿主页面性能。
- **多频道**：按话题或内容类型分频道，每个频道独立配置规则和欢迎语。
- **双模式用户**：访客匿名即开即用；注册用户解锁私信、@ 提及、声誉积分和身份徽章。
- **管理后台**：频道管理、消息审核、用户封禁/解封、举报处理，统一在一个清晰的 SPA 中完成。
- **安装向导**：首次启动图形化引导，测试数据库和缓存连接，自动生成带详细注释的配置文件，无需手写配置。

## 核心差异化

市面上没有一款方案能同时满足：**嵌入在站内 + 完全自托管 + 价格一次到位**。

| 维度 | ChatSphere | QQ群/微信群 | Intercom/Crisp | Discord |
|------|-----------|------------|----------------|---------|
| 数据归属 | 自己服务器 | 平台 | 平台 | 平台 |
| 封号风险 | 无 | 高 | 低 | 低 |
| 嵌入在站内 | ✓ | ✗ | ✓ | ✗ |
| 买断定价 | ✓ | 免费 | ✗ | 免费 |
| 社区功能（声誉/频道/旗帜） | ✓ | 部分 | ✗ | ✓ |
| 部署门槛 | 低（向导） | 无 | 无 | 低 |

核心优势是**自主掌控**：数据不出自己的服务器，没有月费，没有平台生杀予夺。对于任何有粉丝社区需求的独立站长，这是现有方案都无法提供的组合。

## 目标用户

**主要用户：内容站长 / 独立创作者**
运营影视、音乐、游戏、体育等垂直内容网站或 App，有活跃粉丝群体，曾依赖 QQ 群或微信群维系社区。有基础的服务器部署能力，核心诉求是：社区不消失、数据不丢、运营成本可控。

**次要用户：独立开发者 / 小型 SaaS 创始人**
希望在自己产品里加入实时讨论功能，不想从零开发 WebSocket + 管理后台这套系统，愿意为省时间一次性购买现成方案。

**地域**：全球用户，产品界面和文档以英文为主，无语言限制。

---

## 成功标准

**第一优先级（自用）**
- 在自己的影视网站/App 上稳定运行，完整替代 QQ 群
- 影迷社区日活持续增长，不再依赖任何第三方平台

**第二优先级（商业化）**
- GitHub 开源，建立公开信任
- 完成第一笔买断或订阅销售
- SaaS 托管版上线后，订阅收入覆盖服务器成本

**产品质量基线**
- 新用户从下载到 widget 上线 < 30 分钟
- Widget 嵌入后宿主页面加载影响 < 50ms
- 举报处理工具完善，社区能在低干预下自行运转

---

## 产品范围（v1）

**包含**
- 嵌入 widget（匿名 + 注册双模式、emoji、语音输入、国家旗帜、声誉徽章）
- 注册用户专属：私信、消息 @ 提及通知
- 管理后台（频道 CRUD、消息管理、用户封禁/解封、举报处理）
- 安装向导（图形化引导，自动生成 `config.yaml`）
- WebSocket 实时通信 + Redis 历史缓存 + MySQL 持久化
- Docker Compose 一键部署
- 文档与嵌入代码生成器

**明确排除（v1）**
- 文件/图片上传
- 云托管 SaaS 版本（架构预留入口，v1 不交付）

## 商业模式

| 方案 | 价格 | 说明 |
|------|------|------|
| **买断 · 单域名** | $199 永久 | 自托管，1个域名，永久授权 |
| **买断 · 无限域名** | $499 永久 | 自托管，无限域名，适合开发者/代理商 |
| **SaaS Starter** | $9.9/月 · $6.9/月按年（共$83/年） | 托管，1域名，5频道 |
| **SaaS Pro** | $19.9/月 · $12.9/月按年（共$155/年） | 托管，无限域名和频道，优先支持 |

买断约3年回本（vs 对应年付方案），适合有服务器且愿意自己维护的技术用户；SaaS 适合想开箱即用、无需管理基础设施的创作者。

## 愿景

两到三年后，ChatSphere 成为独立站长的默认社区基础设施——就像 WordPress 是博客的默认选择一样。每一个不想被平台卡脖子的内容创作者，都知道 ChatSphere 的名字。

买断版让技术用户完全掌控自己的社区；SaaS 托管版让没有服务器背景的创作者也能零门槛使用。两条路并行，覆盖从极客到普通站长的完整用户谱系。
