# ChatSphere

**Global Embeddable Chat Platform**

Embed a live community chat widget into any website or application with a single `<script>` tag. Self-hosted, real-time, and built for high traffic.

---

## Features

- **Drop-in widget** — one `<script>` tag embeds a floating chat on any page
- **Multi-channel** — create as many channels as you need from the admin panel
- **Anonymous + registered users** — visitors can chat immediately; accounts unlock identity and reputation
- **Real-time** — WebSocket-powered, Redis-cached message history
- **Setup wizard** — first run opens a guided installer; generates a fully-annotated `config.yaml`
- **Admin panel** — manage channels, messages, users, and reports from a clean dashboard
- **Country flags** — geo-based flags shown next to each message
- **Reputation system** — admins assign reputation scores displayed as badges
- **Voice input** — browser Speech API support (Chrome / Edge)
- **Expandable widget** — side-panel view with community rules and stats

## Quick Start

### 1. Prerequisites

| Dependency | Minimum version |
|------------|-----------------|
| Go         | 1.21            |
| MySQL      | 8.0 (or TiDB)   |
| Redis      | 7.0 (or Upstash)|

### 2. Build

```bash
git clone https://github.com/wuekevin/chatsphere.git
cd chatsphere
make build
```

### 3. First Run

```bash
./chatsphere
# → opens http://localhost:8080 — follow the Setup Wizard
```

The wizard will:

1. Test your MySQL connection and run migrations
2. Test your Redis connection
3. Create the admin account
4. Configure your site name and default channel
5. Write a commented `config.yaml` to disk

After the wizard completes the server starts automatically.

### 4. Embed the Widget

Go to **Admin → Widget & Embed** and copy the snippet:

```html
<script
  src="https://your-domain.com/widget/chatsphere.js"
  data-server="https://your-domain.com"
  data-channel="general"
  data-position="bottom-right">
</script>
```

Paste it just before `</body>` on any page.

## Configuration

`config.yaml` is generated by the installer and contains detailed inline comments for every setting. Never commit it — it holds database credentials.

Key sections:

```yaml
server:
  host: "0.0.0.0"
  port: 8080
  secret_key: "..."      # JWT signing key (auto-generated)
  allowed_origins: ["*"] # CORS whitelist

database:                # MySQL / TiDB connection
  host: ...

cache:                   # Redis / Upstash connection
  host: ...

chat:
  max_message_length: 200
  max_history: 500
  rate_limit_seconds: 3
  allow_anonymous: true

admin:
  path: "/admin"
```

To reconfigure, delete `config.yaml` and restart — the installer runs again.

## Widget API

```js
// Auto-init via data attributes (see above)

// Manual init with full options
ChatSphere.init({
  server:   'https://your-domain.com',
  channel:  'general',
  position: 'bottom-right',   // or 'bottom-left'
  title:    'Community Chat',
  notice:   'Be friendly. No spam.',
  telegram: 'https://t.me/yourcommunity',
});

// Runtime methods
ChatSphere.setTitle('Live Chat');
ChatSphere.setNotice('Server maintenance at 02:00 UTC');
```
